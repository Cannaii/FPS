# 中文界面字体

- Noto Sans SC，Google Fonts 官方仓库：https://github.com/google/fonts/tree/main/ofl/notosanssc
- 原始文件：`NotoSansSC[wght].ttf`，下载后仅重命名为`NotoSansSC.ttf`，未修改字体数据。
- 许可证：随附`NotoSansSC-LICENSE.txt`（SIL Open Font License 1.1）。
- 来源：https://raw.githubusercontent.com/google/fonts/main/ofl/notosanssc/NotoSansSC%5Bwght%5D.ttf
- TMP按需生成中文字形图集；字体随项目打包，不读取系统字体或Cowsins资源。
